## 说明

尝试**利用生成式 AI**，根据文档字符串（docstring）的描述完成 `sol()` 函数，使得 `sol()` 的返回值满足 `sat()` 函数的要求（即 `sat()` 返回 **True**，表示已满足要求）。

最后，请将“正确”的解决方案（无论是 AI 生成的还是您修改后的）放入 `problemX.py` 文件中的 `sol()` 函数内。请注意不要修改 `sat()` 函数。

注意：文档字符串中的示例和参数仅供参考。请勿在第 4 题和第 5 题中用硬编码（hardcode）解法。

您可以在本地 VS Code 编辑器中运行已实现的代码，以验证程序输出是否为 `True`。您可以自行尝试不同的输入例子。
